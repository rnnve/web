## Explore the site

Rynnie is a personal portfolio built with Next.js, React, TypeScript, and Tailwind CSS. It brings together projects, listening history, and anonymous questions.

- [Website](/): introduction, Discord profile, and live Spotify status.
- [Developing](/developing): selected repositories, the current year's contribution calendar, and technology stack.
- [Listening](/listen): recent listening history and track and artist rankings.
- [Ask](/ask): leave an anonymous question.

## Start here

Read the [Introduction](./introduction), then [get the project running](./getting-started.mdx). [Customize the interface](./customization.mdx), browse [Components](./components), or open [Development](./introduction/development) for repository details and scripts.

## About these docs

These guides describe the website and its local development workflow. Documentation is written in MDX under `content/docs` and rendered with Fumadocs. Use the sidebar to browse, the search button to find a topic, or the table of contents to jump within a page.
