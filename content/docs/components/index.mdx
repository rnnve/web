## Overview

This section lists the reusable pieces that make up Rynnie. Open a group for its components, then a page for path, purpose, and notes.

| Group | What lives here |
| ----- | --------------- |
| [UI](./ui) | Button, Badge, Card, Dialog, and other primitives |
| [Layout](./layout) | Shells, navbar, background, and shared chrome |
| [Status](./status) | Spotify, live status, and GitHub widgets |
| [Effects](./effects) | Aurora and logo loop |
| [Home](./home) | Age calculator and stacks |
| [Settings](./settings) | Language and site settings |
| [Feedback](./feedback) | External link confirmation |
| [Open Graph](./open-graph) | OG image template |
| [Docs](./docs) | Docs shell and BranchedMenu |
| [Brand](./brand) | Logo marks |

## How to browse

Use the **Components** section in the sidebar: **Intro**, then a group such as **UI**. Prefer changing shared UI under `components/ui` and route-specific pieces under `app/components`.
