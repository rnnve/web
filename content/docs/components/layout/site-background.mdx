## Purpose

Renders React Bits ShapeGrid behind the portfolio and new-tab page. Both `hoverColor` and `hoverFillColor` follow `--site-accent` without resetting the grid.

## Source

`app/components/layout/site-background.tsx`

## Behavior

Cross markers drift diagonally, twinkle, and react to pointer movement across the page. Hover highlights use the site accent. Click cascades are disabled. Reduced motion stops grid drift and twinkling.
