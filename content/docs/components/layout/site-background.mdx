## Purpose

AeroShards background with live accent colors and a vector shard fallback.

## Source

`app/components/layout/site-background.tsx`

## Group

Layout

## Notes

Both shard and accent colors follow `--site-accent`, including changes during playback and the default color when playback stops. The effect updates colors without recreating the GPU scene.

Pointer movement, clicks, and holds interact with the shards while page links and controls remain usable. Reduced motion is respected. Browsers without WebGPU, or with a GPU initialization error, use an animated vector shard scene.
