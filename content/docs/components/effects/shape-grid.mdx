## Source

`app/components/effects/ShapeGrid.jsx` and `ShapeGrid.css`.

ShapeGrid uses Canvas 2D and needs no additional dependencies. It supports multiple cell shapes, drift, pointer trails, twinkling, and optional click cascades. `SiteBackground` configures cross markers and passes the live site accent as both the hover border and hover fill color.
