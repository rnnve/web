## Source

`app/components/effects/AeroShards.jsx` and `AeroShards.css`.

The JavaScript and CSS component uses `vgpu`. `SiteBackground` renders it across the portfolio with both `shardColor` and `accentColor` set to the live site accent.

## Behavior

The background includes floating glass shards, depth markers, pointer parallax, click pulses, and gathering while the pointer is held. Interactive page controls are excluded from click and hold effects. Reduced motion freezes the flow and disables pointer effects.

Use `onError` to provide a fallback when WebGPU is unavailable or fails. The site falls back to an animated vector shard scene.
