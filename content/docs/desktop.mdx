## Enter and leave

Use the Desktop button to the left of Docs at the bottom-right of the website, or open `/-` directly. The desktop starts with no windows open. Switching pulls the current screen out of focus and brings the next one forward when view transitions are supported. Reduced-motion preferences disable the movement.

The taskbar's power menu offers **Return to site**, **Restart desktop**, and **Cancel**. Restart closes the current windows; it does not reboot your computer or clear listening snapshots.

## Apps

### Listening

Browse history, top tracks, and top artists. Use the library search to filter a view and the period selector to change rankings. Listening snapshots are cached per browser tab, including across reloads. Refresh fetches a new snapshot.

### Ask

The anonymous mail composer accepts up to 1,000 characters. A failed delivery keeps the draft for retry. Successful delivery locks sending for the current browser session. Minimizing the window preserves an unsent draft; closing the window discards it.

### Developing

Browse projects in the explorer, read repository details, and inspect the current UTC year's contribution calendar. Day intensity reflects its contribution count relative to the busiest day. Public contribution data and repositories may be temporarily unavailable when their upstream services cannot be reached.

## Windows and taskbar

Drag title bars on larger screens to move windows. Use minimize, maximize, restore, and close controls. The taskbar reopens running apps. **Show desktop** hides visible windows and restores them when selected again.

On mobile, apps fill the available workspace above the taskbar. The launcher supports app search and Enter to open a result; Escape dismisses it.

## Appearance and utilities

WebOS uses a monochrome shadcn interface with the live site accent. The Settings app controls window animations and respects device reduced-motion preferences. Files, Terminal, Portfolio, and New tab are available in the launcher. Terminal is a simulated command interface: `help` lists supported commands; it does not execute system commands.
