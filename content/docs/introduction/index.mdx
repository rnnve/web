## What is Rynnie?

Rynnie is my personal website: portfolio, live listening activity, synchronized lyrics, and anonymous questions. It is built with Next.js, React, TypeScript, and Tailwind CSS.

The public site is [rynni.cc](https://rynni.cc). Source lives in the [rnnve/web](https://github.com/rnnve/web) repository.
