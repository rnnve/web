## What is Rynnie?

Rynnie is my personal website: portfolio, live listening activity, synchronized lyrics, anonymous questions, and a browser desktop called WebOS. It is built with Next.js, React, TypeScript, and Tailwind CSS.

The public site is [rynni.cc](https://rynni.cc). Source lives in the [rnnve/web](https://github.com/rnnve/web) repository.
